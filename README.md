## 🚀 Getting Started

### Prerequisites

* Python
* Jupyter Notebook
* Basic Python programming knowledge
* Git
* A code editor such as Visual Studio Code

### Clone the Repository

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd "Data Science"
```

Replace `<YOUR-GITHUB-REPOSITORY-URL>` with the actual URL of your GitHub repository.

### Set Up a Virtual Environment

On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### Install Common Libraries

```bash
python -m pip install numpy pandas matplotlib seaborn plotly scipy jupyter
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the relevant learning folder and select a notebook to begin.

*Note: Individual modules may require additional dependencies.*
