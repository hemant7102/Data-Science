# NumPy Learning Repository

A practical collection of my **NumPy learning, revision, and experimentation notebooks** covering fundamentals, array manipulation, advanced operations, numerical computing, and visualization.

This repository is part of my **Data Science learning journey**, where I am building my Python and numerical computing fundamentals step by step.

---

##  Contents

The repository currently contains the following NumPy notebooks:

| Notebook                         | Description                                                                                                                                 |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `numpy.ipynb`                    | NumPy fundamentals, array creation, dimensions, attributes, data types, reshaping, and array operations                                     |
| `numpy2.ipynb`                   | NumPy revision covering array creation, zeros, ones, identity matrices, `arange`, `linspace`, shape, size, dtype, and memory concepts       |
| `Advanced numpy.ipynb`           | Advanced NumPy concepts including performance, memory usage, advanced indexing, broadcasting, and mathematical formulas                     |
| `Numpy_tricks.ipynb`             | Useful NumPy functions and techniques such as sorting, appending, concatenation, unique values, expanding dimensions, `where`, and indexing |
| `Numpy-3D-Graphs-Revision.ipynb` | Meshgrids and 3D graph visualization including mathematical surfaces                                                                        |
| `numpy-Graph-plot.ipynb`         | NumPy-based numerical data generation and basic graph plotting                                                                              |
| `quize_numpy.ipynb`              | NumPy practice and quiz-style problems                                                                                                      |
