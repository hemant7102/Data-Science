# Pandas Learning

A practical collection of **Pandas learning, revision, DataFrame operations, Series methods, data manipulation, and visualization notebooks**.

This section is part of my broader **Data Science & Machine Learning roadmap**, focusing on using Pandas for data manipulation, analysis, and exploration.

---

##  Notebooks

| Notebook                     | Description                                                                                                          |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `series-method.ipynb`        | Important Pandas Series methods and operations                                                                       |
| `Pandas-DataFrame2.ipynb`    | DataFrame operations, sorting, ranking, indexing, missing values, duplicates, `apply()`, and practical data analysis |
| `Pandas-Graph-ploting.ipynb` | Pandas visualization using built-in plotting with Matplotlib                                                         |

---

##  Topics Covered

### Series

* Series creation
* Data types
* `astype()`
* `between()`
* `clip()`
* `drop_duplicates()`
* Series indexing and filtering

### DataFrame Operations

* Creating DataFrames
* Reading CSV files
* Sorting values
* Sorting by multiple columns
* Ranking
* Setting an index
* Resetting an index
* Renaming columns and indexes
* Dropping rows and columns
* Removing duplicate values

### Missing Data

* `isnull()`
* `notnull()`
* `hasnans`
* `dropna()`
* `fillna()`
* Forward filling
* Handling missing values in specific columns

### Data Analysis

* `value_counts()`
* `unique()`
* `nunique()`
* Boolean filtering
* Conditional selection
* Applying custom functions
* Practical analysis using IPL and movie datasets

### Visualization

The Pandas visualization notebook covers:

* Line plots
* Bar plots
* Histograms
* Box plots
* Scatter plots
* Area plots
* Pie charts

Pandas plotting provides a convenient interface for creating quick visualizations directly from Series and DataFrames, using Matplotlib as its backend.
